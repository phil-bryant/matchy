# Gitignore Requirements

## Scope

Applies to repository ignore policy and generated local artifacts configured in `.gitignore` for this project.

R001  Statement: Exclude local build output from version control.
Design: Ignore repository-local build directory `.build/` recursively.
Rationale: Build artifacts are machine-generated, high-churn, and dramatically increase push size.
Tests:
- R001-T01: Run a local build and verify new files under `.build/` do not appear in `git status`.

R005  Statement: Exclude Xcode DerivedData and user-specific metadata from version control.
Design: Ignore `DerivedData/`, `*.xcuserdatad/`, and `*.xcuserstate`.
Rationale: These paths are local IDE state and are not portable across machines.
Tests:
- R005-T01: Build/open project in Xcode and verify DerivedData/user metadata do not appear in `git status`.

R010  Statement: Keep project source and shared project configuration tracked.
Constraints:
- Do not ignore `Sources/` source files.
- Do not ignore `Tests/` test files.
- Do not ignore `Package.swift`.
Tests:
- R010-T01: Verify package sources and tests remain tracked after ignore updates.

R015  Statement: Remove accidentally tracked generated artifacts from Git index without deleting local files.
Design: Use cached removals (`git rm -r --cached`) for ignored artifact paths.
Rationale: Keeps local developer caches intact while cleaning repository history moving forward.
Tests:
- R015-T01: Run cached removal for `.build/` and verify files are staged as deletions but remain on disk.

R020  Statement: Enforce that ignored artifact paths are not tracked after cleanup.
Design: Verify `git ls-files` contains no entries under ignored build/cache paths.
Tests:
- R020-T01: Run `git ls-files | rg '^.build/'` and confirm no output.

R025  Statement: Prevent local `.build/` and `.security-reports/` artifacts from appearing in `git status` as untracked files.
Design: Keep `.build/` and `.security-reports/` in `.gitignore` and enforce with automated shell tests.
Rationale: Failing tests catch ignore regressions before local build or security-scan artifacts pollute commits.
Tests:
- R025-T01: Run `bats Tests/sh/.gitignore.bats` and verify `.build/` and `.security-reports/` guard tests pass.

R030  Statement: Exclude the project virtual environment from version control.
Design: Ignore `*-venv/` at repository root to match `02_create_venv.sh` naming (`<cwd-basename>-venv`).
Rationale: Venv trees are machine-local, large, and reproducible from `requirements.txt` via project scripts.
Tests:
- R030-T01: Run `bats testing/sh/.gitignore.bats` and verify the venv ignore regression test passes.
- R030-T02: Create a file under `matchy-venv/` (or current repo basename venv) and verify `git check-ignore` reports it ignored.

R035  Statement: Exclude Python bytecode caches from version control.
Design: Ignore `__pycache__/` directories and `*.pyc` files anywhere in the repository.
Rationale: Bytecode is interpreter-generated, machine-local, and recreated automatically on import.
Tests:
- R035-T01: Run `bats testing/sh/.gitignore.bats` and verify the `__pycache__` ignore regression test passes.
- R035-T02: Verify `git check-ignore` reports a nested `__pycache__/module.cpython-312.pyc` path as ignored.
